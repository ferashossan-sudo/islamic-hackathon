# ليطمئنّ قلبي

> ﴿قَالَ أَوَلَمْ تُؤْمِن قَالَ بَلَىٰ وَلَٰكِن لِّيَطْمَئِنَّ قَلْبِي﴾ [البقرة: 260]

مساعد ذكاء اصطناعي عربي، مجهول وبلا تسجيل دخول، يحاور من تمر عليهم أسئلة علمية أو وجودية تُطرح على أنها تعارض الإسلام: نشأة الكون، وهل الكون صدفة، وأصل الإنسان، والحكمة من الشر والمعاناة، والوحي والعلم. يناقش بالعقل والعلم أولاً ثم بالدليل الشرعي، بأسلوب محترم وبالعامية إن شاء السائل، **ومن إجابات راجعها واعتمدها المراجع الشرعي للفريق فقط**.

مشاركة في **تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي**، المسار الأول: الحوار المعرفي والإجابات الموثوقة.

- **الرابط الحي:** https://ltq-app.onrender.com
- **الفريق:** فراس (قائد الفريق والتطوير)، وسالم (التقنية والتقييم)، وعبدالله (المراجعة الشرعية).

## المبدأ: النموذج يختار ويحاور، ولا يؤلف المحتوى

| الطبقة | من أين تأتي |
|---|---|
| الآيات | من ملف المصحف المحلي فقط، بمرجعها. النموذج لا يكتب نص آية أبداً، بل يضع علامة يملؤها الخادم |
| الأحاديث | من الإجابة المعتمدة فقط، بنصها ودرجتها ورابط للتحقق |
| المعلومات العلمية | من الإجابة المعتمدة، ولكل معلومة درجتها: حقيقة ثابتة، أو نظرية راجحة، أو فرضية |
| الحوار | يكتبه النموذج من إجابة معتمدة واحدة فقط، ويمر بفاحصين (G13 وG14)، وإلا حُذف وعُرضت الإجابة المعتمدة وحدها |
| الامتناع | إن لم توجد إجابة معتمدة مناسبة قال ذلك بوضوح، وأحال إلى جهة مختصة |
| رسائل الضيق | تُكشف قبل أي خطوة، ويُرد عليها برد ثابت وأرقام دعم رسمية، ولا تُرسل إلى أي نموذج |

## كيف تصل الرسالة إلى الرد

1. كشف رسائل الضيق بقائمة ثابتة (G7).
2. التحقق من الرسالة، وحد الرسائل.
3. اللغة، والآية المنقولة بخطأ (G3).
4. **استدعاء التوجيه:** يصنّف الرسالة ويختار معرّف إجابة معتمدة أو «لا شيء» (مخرَج JSON مقيّد بمخطط).
5. جدول القرار: إجابة، أو امتناع، أو إحالة بحسب السبب.
6. تركيب الإجابة من الإجابة المعتمدة والمصحف، والتأكيد النهائي (الآيات تساوي المصحف، والأحاديث تساوي الإجابة).
7. **الحوار:** استدعاء يكتب رداً حوارياً من الإجابة المعتمدة وحدها، ثم الفاحص الآلي G13، ثم **استدعاء تحقق** G14 يطلّع أي ادعاء بلا سند (مع محاولة إعادة واحدة).
8. إن تعطل النموذج أو بلغ الحد اليومي: **الوضع المخفّف**، بحث محلي بلا ذكاء اصطناعي، ويُعرض في العرض الحي بـ `?mode=offline`.

## التشغيل

يحتاج Python 3.13 و[uv](https://docs.astral.sh/uv/).

```bash
uv sync
uv run pytest -q
```

**دون أي مفتاح** (البحث المحلي وحده):

```bash
LLM_ENABLED=false uv run uvicorn app.main:app --port 8000
```

**مع النموذج:** انسخ `.env.example` إلى `.env`، وضع فيه `ANTHROPIC_API_KEY` مع `ROUTER_PROVIDER=anthropic` (Claude Haiku 4.5 للفهم والتدقيق، وSonnet 5.5 للحوار)، و`GEMINI_API_KEY` احتياطاً، ثم:

```bash
uv run --env-file .env uvicorn app.main:app --port 8000
```

**التقييم:**

```bash
uv run --env-file .env python eval/run_eval.py --set critical --system ours --runs 3
uv run python eval/run_eval.py --set critical --system lexical
```

## القاعدة المعرفية ودورة الاعتماد

- الإجابات في `content/kb.json`. لا يُعرض إلا ما حالته «معتمد» وبصمة اعتماده (`approved_hash`) تطابق محتواه الظاهر، فأي تعديل بعد الاعتماد يُسقطه حتى يُعتمد من جديد.
- تُصاغ المسودة بمساعدة الذكاء الاصطناعي من مصادر مفتوحة فقط، ويطابقها وكيل ثانٍ جملة جملة، ثم يراجعها الفريق، ثم يعتمدها المراجع الشرعي. التفاصيل في `CONTENT.md`.
- الأداة: `scripts/kb_tool.py` (إضافة، وفحص، واعتماد، وملف مراجعة للجوال).

## الوثائق

| الملف | المحتوى |
|---|---|
| `SOURCES.md` | المصادر والأدوات والتراخيص |
| `CONTENT.md` | المنهج الشرعي والعلمي، ودورة المراجعة |
| `EVAL.md` | منهج التقييم والنتائج |
| `OPERATIONS.md` | التشغيل والتكلفة والاستمرار |
| `STARTING_POINT.md` | ما وُجد قبل أيام التحدي |
| `PROGRESS.md` | سجل التقدم اليومي |

## الحدود

- العربية فقط، والرسالة بغيرها تأخذ إحالة باللغتين.
- يجيب في المواضيع التي لها إجابة معتمدة فقط، ويمتنع في غيرها.
- ليس منصة فتوى، ولا بديلاً عن العالم أو المختص.
